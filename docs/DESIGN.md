# DESIGN — APEX Detailing, примерка дисков

План токенов по скиллу `frontend-design` (сначала план, потом сверка с брифом, потом код).

## Цвет

| Токен | Значение | Роль |
| --- | --- | --- |
| `--bg` | `#0A0B0D` | фон (задан брифом) |
| `--surface` / `--surface-2` | `#121418` / `#1A1D22` | карточки, поля |
| `--line` | `#2A2E35` | границы |
| `--text` / `--text-2` | `#F2F2F2` / `#9CA2AB` | основной и вторичный текст |
| `--accent` | `#C9A878` | тёплый металлик: выбранное, цены, основная кнопка, свет в гараже |

Один акцент на всё. Статус «в наличии» — приглушённый зелёный, не акцент.

## Шрифт

- Tenor Sans — заголовки и названия дисков: узкий гуманистический гротеск с «бутиковой» подачей, без спортивной агрессии.
- Golos Text — интерфейс и цифры (`tabular-nums` в ценах).
- Шкала: 13 / 15 / 17 / 24 / clamp(40–76).

## Принципы

1. Машина — главный объект. Смелость потрачена в одном месте: гараж с подиумом и светом. Всё вокруг тихое.
2. Движение только в ответ на действие: диск кроссфейдом 200 мс с доворотом 15°, нажатие 0.98, переходы 250 мс, одна кривая `cubic-bezier(0.23, 1, 0.32, 1)`. Исключение — один момент на главной: штатный диск сменяется диском APEX.
3. Сверка с брифом: тёмный фон с одним акцентом — это дефолт №2 из списка скилла, но его прямо задаёт бриф («тёмная премиальная, акцент тёплый металлик»), поэтому он оставлен. Своеобразие даёт сцена-гараж и типографика Tenor Sans, а не цвет.
